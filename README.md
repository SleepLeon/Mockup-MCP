# Steering MCP

A mockup MCP server powering a conversational weekly media steering assistant. Connects to synthetic MMM output data to help media managers decide where to increase or decrease spend across countries and channels each week.

## Repo structure

```
steering-mcp/
  data/
    synthetic.json        ← generated by generate_data.py
  server.py               ← MCP server (stdio, entry point)
  generate_data.py        ← regenerates synthetic data
  system_prompt.md        ← system prompt for the steering assistant
  README.md
```

## Setup

```bash
pip install mcp
python generate_data.py   # creates data/synthetic.json (240 rows)
python server.py          # starts MCP server on stdio
```

## MCP tools

| Tool | Description |
|------|-------------|
| `get_steering_snapshot` | Full week's data sorted by abs(spend_delta). Call at session start. |
| `get_country_channel` | Filter by country, channel, or both. |
| `run_scenario` | Simulate budget reallocation, returns projected revenue impact. |
| `get_saturation_flags` | All decrease/watch rows above a saturation threshold. |

## Connecting to Claude Desktop / Claude Code

Add to your MCP config (`~/.claude/claude_desktop_config.json` or equivalent):

```json
{
  "mcpServers": {
    "steering": {
      "command": "python",
      "args": ["/absolute/path/to/steering-mcp/server.py"]
    }
  }
}
```

## System prompt

See [system_prompt.md](system_prompt.md). Paste it as the system prompt when starting a Claude session with this MCP connected.

## Data story (seeded rows)

The synthetic data is seeded to tell a clear pitch narrative:

- **Opportunities**: DE paid_search (+€22k, ROI 3.4), PL paid_search (+€18k, ROI 3.1), NL paid_social (+€15k, ROI 2.7)
- **Over-saturated**: ES display (sat 96%, ROI 0.7), FR display (sat 94%, ROI 0.8), IT display (sat 91%, ROI 0.9)
- **Watch**: SE paid_social (sat 82%), AT paid_search (sat 79%), BE display (sat 80%)

Key demo scenario: *shift €55k from FR+ES+IT display → DE+PL paid_search+NL paid_social* → projects ~€112k incremental revenue, all target channels stay below saturation.
